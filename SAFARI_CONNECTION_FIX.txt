Issue: Safari shows "Can't connect to the server"
Solution: 
  1. Make sure Terminal shows "running on port 3000"
  2. Try http://127.0.0.1:3000 instead of localhost
  3. Clear Safari cache (Develop → Clear Caches)
  4. Restart Safari

Issue: Safari shows blank page
Solution:
  1. Open Safari Developer Tools (Cmd+Opt+I)
  2. Check Console tab for errors
  3. Try hard refresh (Cmd+Shift+R)

Issue: CORS errors in Safari
Solution:
  1. The server already has CORS enabled
  2. Try different browser
  3. Check Console for specific error
