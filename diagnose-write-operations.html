🔍 DynamoDB Write Operations Diagnosis

Analyzing why the platform can READ from DynamoDB but can't WRITE (create/update)

🎯 Problem Analysis

The platform successfully reads data (merchants list loads) but write operations fail with errors like "Merchant not found" or "Update failed".

Possible Root Causes:

1. Table Name Mismatch
Backend environment uses `wizzcentral-backend-merchants-dev` but actual table is `order-receiver-businesses-dev`
2. Permission Issues
Lambda functions have read permissions but lack write permissions for the correct tables
3. Authentication Context
Write operations require proper user context that might be missing or malformed
4. Primary Key Mismatch
Code uses wrong primary key name (already fixed for merchants, but might affect other tables)
