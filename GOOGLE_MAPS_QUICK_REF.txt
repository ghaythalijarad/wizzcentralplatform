Step 1: Enable APIs
   → https://console.cloud.google.com/apis/library
   → Project: "wizz business"
   → Enable: Geocoding, Maps JS, Places

Step 2: Create API Key
   → https://console.cloud.google.com/apis/credentials
   → Create Credentials → API Key
   → Copy the key (AIzaSy...)

Step 3: Restrict Key (CRITICAL!)
   → Click "Restrict Key"
   → API Restrictions:
     ✅ Geocoding API
     ✅ Maps JavaScript API
     ✅ Places API
   → Application Restrictions:
     • http://localhost:3000/*
     • https://yourdomain.com/*

Step 4: Enable Billing
   → https://console.cloud.google.com/billing
   → Add credit card
   → Set budget alert: $50/month

Step 5: Add Key to Project
   → Edit: google-maps-config.js
   → Replace: YOUR_GOOGLE_MAPS_API_KEY_HERE
   → With: Your actual key

1. Cache Results
   Cities don't move! Cache geocoding results to save $$

2. Use Language Parameter
   Always add: &language=ar&region=IQ for Iraqi results

3. Debounce Search
   Wait 500ms before searching to reduce API calls

4. Lazy Load Maps
   Only load map when user scrolls to it

5. Set Budgets
   Alert at 50%, 90%, 100% to avoid surprises

6. Monitor Usage
   Check console.cloud.google.com weekly

7. Rotate Keys
   Change API keys every 3 months for security
