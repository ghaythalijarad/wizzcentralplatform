🐛 TROUBLESHOOTING

Problem: "window.dataService exists: false"
Solution: data-service.js not loaded properly
   → Check: grep "data-service.js" frontend/pages/dashboard.html

Problem: "AWS object exists: false"
Solution: AWS SDK not loaded
   → Check: grep "aws-sdk" frontend/pages/dashboard.html

Problem: "AccessDenied" errors
Solution: IAM permissions issue
   → Run: aws sts get-caller-identity
   → Run: aws dynamodb scan --table-name WhizzMerchants_Businesses --select COUNT

Problem: Function never called
Solution: dashboard.js not loaded or has syntax error
   → Check: Browser Sources tab for dashboard.js
   → Check: Console for JavaScript errors
