  ⚠️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Port 3000 already in use
Solution:
    lsof -i :3000
    kill -9 $(lsof -t -i:3000)
    # Then try starting again

Problem: Dependencies not installed
Solution:
    cd /Users/ghaythallaheebi/WhizzEcoSystem/whizzEcosystem/whizzCentralPlatform
    npm install
    # Then try starting again

Problem: AWS credentials error
Solution:
    aws sts get-caller-identity --profile wizz-drivers-ghayth-dev
    # If error, configure AWS credentials

Problem: Can't connect in browser
Solution:
    1. Check server is running in terminal
    2. Make sure you see "running on port 3000"
    3. Try http://127.0.0.1:3000 instead of localhost
