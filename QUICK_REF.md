# 🚀 Quick Reference - Regions Management

## ⚡ 30-Second Start

```bash
npm run playground
```
Open: http://localhost:3000

---

## 🎯 Three Basic Actions

### 1. Search
```
Type "Najaf, Iraq" → Click "Go"
```

### 2. Save  
```
Click "💾 Save" button → Done!
```

### 3. Export
```
Click "📤 Export Data" → Download JSON
```

---

## 🗺️ Interface Map

```
LEFT SIDEBAR:          RIGHT SIDE:
```

## 🆘 Quick Fixes

**Server not running?**
```bash
npm run playground
```

**Page blank?**
- Check terminal for errors
- Refresh browser (Cmd+R)

**Can't save?**
- Check localStorage enabled
- Clear browser cache
