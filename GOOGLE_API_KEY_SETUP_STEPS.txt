Step 1: Open Google Cloud Console
   ✅ Browser should have opened automatically
   URL: https://console.cloud.google.com/apis/credentials
   Project: wizz-business

Step 2: Enable Places API
   1. Click "+ ENABLE APIS AND SERVICES"
   2. Search: "Places API"
   3. Click "Places API"
   4. Click "ENABLE"
   5. Wait for it to enable (takes a few seconds)

Step 3: Create API Key
   1. Go to: Credentials page
   2. Click "+ CREATE CREDENTIALS"
   3. Select "API Key"
   4. ✅ COPY THE KEY (starts with AIzaSy...)
   5. Keep the popup open!

Step 4: Restrict Key (IMPORTANT!)
   1. Click "RESTRICT KEY" in the popup
   
   2. Set Name:
      WhizzCentral-Regions-Places-API
   
   3. API Restrictions:
      • Select "Restrict key"
      • Check ONLY: ✅ Places API
   
   4. Application Restrictions:
      • Select "HTTP referrers (web sites)"
      • Add these URLs:
        http://localhost:3000/*
        http://localhost:*
        https://*.amplifyapp.com/*
   
   5. Click "SAVE"

Step 5: Copy Your Key

   ⚠️ Keep it safe!
